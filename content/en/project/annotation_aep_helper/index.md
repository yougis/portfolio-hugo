## Project description

The **Annotation AEP Helper** plugin was developed in the context of the **GIS DAY 2025** presentation. It aims to facilitate the integration of recollements (geometric annotations) into the **GEOcalédonian standard** for Earth observation and territorial planning projects.

## Objectives

- Automate the creation of recollements conforming to the GEOcalédonian standard
- Reduce data preparation time for Earth observation projects
- Ensure annotation compatibility with local GIS systems
- Promote reusability of annotation data between projects

## Key features

- Import of existing annotation files
- Automatic conversion to GEOcalédonian recollement formats
- Geographical validation against local standards
- Export to common formats (Shapefile, GeoJSON, GeoPackage)
- Intuitive interface within the QGIS environment

## Technologies used

- **QGIS**: interface and geometry processing
- **Python**: plugin development and georeferencing logic
- **GEOcalédonian standard**: specific formats and constraints
- **AEP**: Earth observation activities
