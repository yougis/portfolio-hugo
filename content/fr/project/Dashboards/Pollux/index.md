## Description du projet

Ce projet vise à développer un tableau de bord interactif sur la plateforme ESRI pour visualiser et analyser les zones d'intérêt environnemental sous pression (gestion de l'eau, érosion, pollution lumineuse, etc.). Ces tableaux de bord intègrent de nombreuses données spatiales détaillées issues de multiples sources de données.

## Compétences exploitées et livrables
- ArcGIS Online
- ArcGIS
- Data Visualisation
- Data Management
